# Oplossingen & examen

Hieronder vind je de uitgewerkte oplossingen van de oefeningen, plus het eind­examen.

> 💡 **Probeer het eerst zelf!** Je leert het meest door eerst zelf te zwoegen en pas daarna
> te vergelijken. Gebruik de oplossingen om je eigen code na te kijken, niet om over te
> schrijven.

Per oefening kun je:
- **▶ Live openen**, de werkende oplossing draait meteen in een nieuw tabblad.
- **&lt;/&gt; Code bekijken**, toont de broncode hieronder, netjes ingekleurd.
