# Nederlandse JavaScript Cursus

Een complete, originele cursus om JavaScript te leren, in het Nederlands, met oefeningen en een
eindexamen-oefening. Inclusief een bijbehorende cursuswebsite.

## Inhoud

- `Nederlandse JavaScript Cursus/`: de cursusmodules (`.md`) en de oefeningen (`oefeningen/`).
- `javascriptcourse/`: de statische cursuswebsite (Bootstrap + JavaScript) die de modules
  inleest en toont. Live op jonastrap.be/javascriptcourse.

## De website lokaal bekijken

De site gebruikt `fetch` op lokale bestanden, dus draai een kleine server in `javascriptcourse/`:

```bash
cd javascriptcourse
npx serve
```

> Deze repo bevat bewust niet het bronboek (PDF) of de losse boekvoorbeelden; alleen de
> zelfgeschreven cursus en de website.
